## Overview

Learn how to list Vydon jobs with the vydon jobs list command.

The `vydon jobs list` command is used to list the currently configured Vydon jobs for a specific account.

## Usage

```bash
vydon jobs list
```

### Aliases

```bash
vydon jobs ls
```
