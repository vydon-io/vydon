# vydon list

## Overview

Learn how to list Vydon accounts with the vydon accounts list command.

The `vydon accounts list` command is used to list the personal and team accounts for a user or api key.

## Usage

```bash
vydon accounts list
```

### Aliases

```bash
vydon accounts ls
```
